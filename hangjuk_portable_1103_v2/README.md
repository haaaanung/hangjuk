# 팀 공유용 실행 패키지 — 1103_v2

이 폴더와 공식 `문제 데이터_수정_1103_v2.zip`만 있으면 통합 제출 엑셀 **하나**를 생성합니다. 기존 hangjuk 저장소, 연구 캐시, 학습 데이터 폴더, GPU는 필요하지 않습니다. Python 3.12에서 실제 실행 검증을 완료했습니다.

## 실행

압축을 풀고 이 README가 있는 폴더에서 터미널을 엽니다.

```powershell
python -m pip install -r requirements.txt
python predict.py --zip "C:\Users\본인계정\Downloads\문제 데이터_수정_1103_v2.zip"
```

Windows에서는 공식 ZIP을 `run_windows.bat` 위로 끌어 놓아 실행할 수도 있습니다. Python이 설치되어 있어야 합니다. 첫 실행은 필요한 패키지를 설치합니다.

완성 파일은 **`output/submission.xlsx`** 입니다. 그 파일을 대회 페이지에 제출합니다. 같은 위치에 진단용 CSV와 `RUN_REPORT.json`도 생기지만 제출 엑셀은 하나입니다. 공식 ZIP의 테스트 CSV 전체를 순차적으로 읽기 때문에 디스크와 CPU에 따라 시간이 달라집니다. 재학습은 하지 않습니다. 이번 컴퓨터의 실제 실행은 약 68초였으며 다른 컴퓨터에서는 달라질 수 있습니다.

## 이번 공유본의 모델과 한계

- Test A는 L127 + 활동 행 확률 평균 후보 하나입니다. 활동 조건은 현재 행의 `zero_step_ratio < 0.5`와 `spatial_spread_m >= 200`입니다. 활동 행이 없는 선박은 전체 행 평균을 씁니다.
- 모델 입력은 현재 행의 기하·좌표·시간 34특징입니다. ID는 대상 선택·예측 집계·제출 정렬에만 씁니다. 선박 이력 프로필이나 학습 ID-라벨 연결은 사용하지 않습니다.
- 포함 모델은 Fold 1~5의 5,897척·3,179,832행으로 이미 학습했습니다. 실행 때 재학습이나 Fold 0 접근은 없습니다.
- 관측된 신규 선박 5 Fold 평균 행 Micro-F1 0.6048은 사후 조합 결과이며 재분할에서 일관되게 재현되지 않았습니다. 확정된 최강 모델이나 실제 Test A 점수라는 뜻이 아닙니다.
- Test B는 동일 선박의 인접 관측 간 변화량을 median/MAD로 정규화한 **성능 미검증 임시 베이스라인**입니다. 최대 이상 시각을 고르고 고정 임계값 6 미만이면 사고시각을 비웁니다. 점수는 보정된 사고 확률이 아닙니다.
- Test B에는 최대 24개 관측 시점 점수를 기입합니다. 실제 사고 정답으로 탐지 성능이나 임계값을 검증하지 않았습니다.

이전 공유본에 엑셀 3개가 있었던 이유는 L127 활동 평균 / L127 전체 평균 / R1 전체 평균의 비교 후보였기 때문입니다. 이번 공유본은 첫 번째 후보만 생성합니다.
