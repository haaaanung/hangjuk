## 선박 항적 기반 조업방식 분류 모델

### 1. 모델 구조

GIS MultiLineString 형태의 선박 항적 데이터를 활용하여 연안복합, 자망, 채낚기연승낚시, 통발의 4개 업종을 분류하는 **LightGBM 기반 앙상블 모델**을 개발하였다.

모델은 서로 다른 특징 표현을 활용하는 세 가지 분류기의 예측을 결합한다.

- **Base Model:** 항적의 이동거리, 직선성, 방향 변화 등 기하학적 특징을 활용
- **Raster Model:** 기본·고급 기하학적 특징에 공간 점유(Occupancy) 및 방향 흐름(Directional Flow) 기반 Raster 특징을 추가
- **Spatial Model:** 항적의 공간적 위치와 분포를 반영하는 특징 기반 모델

각 모델의 클래스별 예측 확률을 가중 평균하고, 업종별 보정 계수를 적용하여 최종 조업방식을 결정한다.

### 2. 모델 주요 특징

- **Geometry 중심 입력:** `geom`만을 분류 입력으로 활용하며, `rfid_id`, `part_dt`, `rfid_time`은 모델 특징에서 제외
- **다중 특징 융합:** 기본 기하학적 특징 77개와 고급 Geometry 및 Raster 특징을 결합
- **LightGBM 학습:** 300회 Boosting, 학습률 0.04, Leaf 63, L1·L2 규제 및 클래스 가중치 적용
- **앙상블 최적화:** Macro-F1을 기준으로 모델별 결합 가중치와 클래스별 보정 계수를 선택
- **시간 기반 검증:** 1~4월 학습, 5월 앙상블 설정 선택, 1~5월 최종 학습, 6월 이후 데이터 평가

### 3. 모델의 차별성

기존 항적 분류 모델이 이동거리와 방향 변화 등 요약 통계에 주로 의존했다면, 본 모델은 **항적의 공간 점유 형태와 방향 흐름을 Raster 특징으로 추가하여 기하학적 표현력을 확장**하였다.

또한 서로 다른 특징을 활용한 모델을 앙상블하고 시간 순서 기반 평가를 적용하여 미래 관측에 대한 분류 성능을 검증하도록 설계하였다.
