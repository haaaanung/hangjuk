# 다음 연구 후보 — 실행 전 브리핑

현재 정확한 제출 후보 구성의 전체 기간 5-fold 검증이 없으므로, 이를 먼저 보고해야 합니다. 아래는 사용자가 선택하기 위한 후보이며 이 커밋에서 추가 학습은 실행하지 않았습니다. Fold 0은 열지 않고 Test A 정답·점수로 설정을 탐색하지 않습니다.

## 1. 항적 주변의 다중 규모 해저지형 (새 정보 범위 확장)

현재 14특징은 현재 행 꼭짓점이 닿은 셀의 수심·경사 통계입니다. 같은 수심이라도 해저 능선, 골짜기, 넓은 평탄면은 주변 지형이 다릅니다. 현재 행 중심과 항적이 닿은 셀 주변의 사전 고정된 1/3/5 km 규모 BPI·거칠기를 구해 비교합니다. NOAA Benthic Terrain Modeler가 BPI·경사·지형 거칠기를 사용하는 점이 방법 근거이지, V-PASS 업종 개선의 증거는 아닙니다.

- 기존 등수심선과 항적 방향의 정렬 실험과 다릅니다. 새로운 것은 주변 공간 범위의 지형입니다.
- 대조: 같은 지역 안에서 새 지형값을 순열한 모델, 기존 수심 모델. 육지·유효 해역 비율은 양쪽에 동일하게 제공합니다.
- 결측은 그대로 유지하며, 최근접 바다 값으로 육지를 강제로 채우지 않습니다.
- 위험: GEBCO 15 arc-second 격자는 미세한 어구 구조를 표현하지 못하고, 새 열이 위치의 재표현에 그칠 수 있습니다.
- 개선 확률·개선폭: 정량 근거 없음. 악화·무변화 가능성을 포함합니다.
- 잠정 비용: 격자 전처리와 2-fold 대조 실험 약 25~45분. 미벤치마크 추정입니다.
- 출처: https://coast.noaa.gov/digitalcoast/tools/btm.html

## 2. 육지·자료 품질을 구분한 수심 입력 (품질 문제 점검)

현재 계산은 육지 고도를 부호만 바꾼 음수 수심도 평균·범위에 포함합니다. 기존 조사에서는 행의 31%가 꼭짓점 절반 이상이 육지 셀에 있었고 직접 측정 셀 비율도 작았습니다. 바다 셀만으로 수심 통계를 계산하되 육지·해역 포함률을 별도 보존하고, TID를 품질 구분에 사용합니다.

- 기존 연구에서 해상 활동 행만 골라 본 진단은 분리도가 약했습니다. 따라서 이것이 큰 개선이라는 근거는 없습니다. 새 검증 범위는 최근 수심 후보의 입력 자체를 같은 행에서 바꾸는 것입니다.
- 대조: 품질·결측 지시자만 변경한 모델 vs 실제 바다 수심 통계 모델. 평가 행은 삭제하지 않습니다.
- 위험: 육지값도 유용한 항구 맥락이어서 제거하면 오히려 나빠질 수 있습니다. 직접 측정 셀만 남기는 방식은 결측이 너무 많아질 수 있습니다.
- 개선 확률·개선폭: 정량 불가. 신규 정보 추가보다 입력 품질 수정에 가깝습니다.
- 잠정 비용: 특징 재계산 포함 약 20~40분. 미벤치마크 추정입니다.
- 출처: https://www.gebco.net/gebco-tid-grid
- 출처: https://www.gebco.net/data-products-gridded-bathymetry-data/gebco2026-grid

## 3. 점 개수 대신 방문 셀·경로 길이로 수심 통계 계산 (기록 밀도 의존 완화)

지금은 모든 꼭짓점이 같은 가중치여서 정박 중 반복 좌표나 기록 밀도가 높은 구간이 수심 통계를 지배할 수 있습니다. 같은 행의 중복 셀에 동등 가중치를 주거나, 부분 내부 선분의 길이로 가중한 수심 표현을 비교합니다. 선박 이력이나 다른 행은 사용하지 않습니다.

- 기존 밀도 증강과 다릅니다. 원시 항적이나 학습 샘플을 바꾸지 않고 외부 수심 통계를 집계하는 방식만 바꿉니다.
- 대조: 기존 꼭짓점 동일 가중 통계, 고정한 방문 셀 동일 가중 통계. 입력 열 수·학습 조건은 같습니다. 경로 길이 방식은 별도 사전 계획 없이는 추가 탐색하지 않습니다.
- 위험: 위치 정보가 이미 대부분이라 통계 변경 효과가 없을 수 있습니다. 정지 행의 길이 0 예외 처리도 사전에 고정해야 합니다.
- 개선 확률·개선폭: 정량 불가. 1순위보다 기대 근거가 약합니다.
- 잠정 비용: 특징 재계산 포함 약 20~40분. 미벤치마크 추정입니다.

## 우선순위

정확한 후보의 5-fold 결과 보고 → 1번 주변 지형 → 2번 품질 구분 → 3번 기록 밀도 의존 완화. 추가 풍속·퇴적물 전체 재도입이나 seed·트리 파라미터 탐색을 우선하지 않습니다. 성공 기준은 같은 분할·같은 집계의 기준선을 넘고 새 대조군보다도 좋아지는지이며, +1%p는 최소 의미 있는 개선 기준으로 사용합니다. +1%p나 +3%p가 나올 것이라고 보장하지 않습니다.
